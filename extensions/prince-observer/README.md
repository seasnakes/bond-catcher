# 小王子消息观察器

安装目录即当前目录。Chrome → 扩展程序 → 管理扩展程序 → 开发者模式 → 加载已解压的扩展程序。

仅观察：
- 益聊：http://103.120.91.153:81，目标“可转债技术交流群三群”的“转债小王子1”。
- MX：https://mx.2026.naaifu.cn，仅观察当前打开页面中已显示的目标频道消息。

内容发送至本机 http://127.0.0.1:5188。后台服务按已配置的规则去重、过滤并转发至指定飞书群。正文与完全相同像素图片在两分钟内匹配；重新压缩图片可能重复。
MX 只读取当前已打开标签页中自然显示的消息。要观察“转债小王子”或“快讯八合一”，需分别将页面停留在对应频道；扩展不主动请求消息接口、不翻页、不打开或刷新 MX 标签页。首次接入时页面旧消息仅存档为 history，不外发。扩展不会读取登录令牌，也不会向来源群发言。

原有的 Chrome 自动启动项 `~/Library/LaunchAgents/com.seasnake.finance-mx-chrome.plist` 已停用。电脑休眠、页面关闭或离开目标频道时不会继续采集。

扩展目前因 MX 登录页显示“账号异常”而保持关闭。恢复前需由用户处理账号状态；恢复后只在已打开且停留目标频道的页面观察自然到达消息。离线期间消息不会自动回补；页面心跳只证明 DOM 观察器在运行，不能证明原站连接或账号状态正常。

移除扩展并刷新来源页即可停止观察，已有数据保留。
