# 快讯八合一监听与过滤

来源：MX「快讯八合一」，专用 Chrome 标签页。目标飞书群：news（oc_b86bb6c1763da033a20c2f99db4f2904），机器人 profile cli_aaa2b0f1d139dcd9。

看板：http://127.0.0.1:5188/news

## 规则

规则代码 `scripts/prince/news_filter.py`，版本 news-v5-placeholder-cleanup。所有原文、图片地址、历史版本保存在原 SQLite 存档，过滤只影响外发。扩展不刷新源站页面；MX 两频道通过已登录网页的只读消息接口定时检查，短暂断线最多回补 8 页，避免无界翻阅历史。`news_decisions` 保存命中原因。

- 英文 [] 或全角 ［］：过滤；已确认的 `[捂脸]`、`[破涕为笑]` 表情标记例外。
- 【】去空白后1–6字符：过滤。新闻常用标签（快讯、要闻、早报、午报、收评、公告、突发、独家、更新、数据、提醒、财联社、新华社、央视新闻）例外保留。该长度规则由用户提出，可能误拦其他短新闻标签，可通过看板回查。
- 券商团队标题、重点/坚定/强烈推荐、推荐名单、券商派点及联系推广、带投资测算的目标价/目标市值、券商调研更新、路演会议邀约：过滤。
- 图片不再统一拦截；正文通过过滤时文字和图片都推送，仅图片（或正文仅免责声明）也推送。收评/盘中/盘后观点标题、明确指数点位与做多窗口、出现至少两组投资评论线索（看好/建议关注 + 估值/市值 + 我们认为/调研等）：待核对，不推送。当前没有 OCR，不保证识别图片内荐股内容。
- 长【新闻标题】、一般经济数据及被新闻引用的机构宏观预测：不单因券商名字或括号过滤。
- 全频道统一免责声明不用于判断，也从网页展示与飞书正文中去掉；SQLite 原文保留。长文按段落或句子分段，分段带序号。
- 图片占位符（如 `4:` 加空行或字面量 `\n`）不单独发送文字；有图片时仅发送图片。其余来源的纯空白、不可见字符文本也不入队。

## 运行

原服务 com.seasnake.finance-prince 内有独立发送队列工作线程。配置 `~/Library/Application Support/finance-prince/news-feishu.json`；与小王子路由严格按 source 与 destination 隔离。扩展 1.2 起通过网页自身已登录的只读接口同时读取 MX 两频道，不依赖选中聊天窗口。页面脉冲每 15 秒检查，Chrome 后台限速时 30 秒闹钟兜底，本机队列每 2 秒检查。验收 `/api/news` 应返回近期 `transport=mx_api`、`status=observing_api` 心跳及 `newestId`，且原站新消息 ID 入库推进。

Chrome 需运行、MX 需登录且电脑需唤醒；扩展会在没有 MX 标签页时后台打开一个。现有两个标签页可保留，但无需分别停留目标频道。旧版临时注入仅供回滚排障：

```js
fetch('http://127.0.0.1:5188/news-collector.js').then(r=>r.text()).then(s=>(0,eval)(s))
```

首次启用只建立已见消息 ID 集合；之后逐条对比 ID，并在短暂断线后回补。数字 ID 不用于判断发布时间先后。只有启用后的 observed、近 30 分钟且过滤通过消息进入 news 群。图片另有 `image_enabled_at` 切换时间，切换前已入库的旧图不批量补发；之后只下载新消息的图片。超过 30 分钟的迟到消息不自动推送；超过 8 页的断档会显示待核对。正文直接发送，无额外频道前缀。两分钟内相同正文按现有幂等 outbox 去重；仅时间前缀或来源尾注不同的转载目前可能重复，未做语义去重。

按 MX 已解码消息的 `createtime` 解析时间，兼容毫秒时间戳与北京时间日期字符串；仍不是独立核验的源发布时间。

停用：配置 enabled=false，已排队消息也停止发送。回滚备份在本地数据目录 before-news-时间戳.sqlite3。无需修改原小王子配置。

验收：`/usr/bin/python3 -m unittest discover -s tests/prince -v`；看板分别查看原文、过滤原因、心跳和发送队列。没有新的符合条件消息时，不能把心跳或历史导入说成已完成实时飞书收发验收。

样本范围：从已加载页面抽样核对，非完整历史。短括号规则与其他规则可能交叉命中，命中数不能相加当作过滤消息数。
