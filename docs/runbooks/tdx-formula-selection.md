# 通达信公式选股结果看板

这条流程直接调用 Windows 通达信 TQ 中已经存在的条件选股公式，不经过飞书，也不会触发交易或修改通达信自定义板块。

## 当前公式

- `单针`
- `异动`
- `ZX`

运行前会通过 `formula_get_all(formula_type=1)` 和 `formula_get_info` 确认公式确实存在、属于条件选股公式，并读取参数和输出定义。

## 数据流程

```text
通达信 TQ 条件选股公式
  → 通达信可转债分类（market=32）
  → formula_process_mul_xg 批量计算
  → runtime/tdx-formula-selections.json 原子快照
  → /api/tdx-formula-selections
  → tdx-formulas.html 只读展示
```

## 更新结果

在仓库目录运行：

```bash
npm run run:tdx-formulas
```

默认口径：

- 通达信可转债分类（`market=32`）；
- 日线、前复权；
- 每只转债提供最近 250 根 K 线；
- 每批 50 只、三个公式串行执行；
- 每批完成后原子更新快照；
- 未完成快照再次运行时自动续跑；
- 不写 `data/board-state.json`，不进入 Git。

如需放弃未完成快照并从头运行：

```bash
npm run run:tdx-formulas -- --fresh
```

验证少量转债时可限制搜索范围：

```bash
npm run run:tdx-formulas -- --limit 50 --fresh
```

不要把 `--batch-size` 提高到 200。现场测试中 50 只一批通常约 1–1.5 秒，200 只单批可能长时间不返回；脚本将批量上限限制为 100。

公式接口只读取通达信已有的盘后 K 线，不会由本脚本自动执行“行情下载”。通达信官方要求先完整下载对应盘后数据，或另行调用 `refresh_kline`。自动批量刷新不建议一次传入过多证券，容易阻塞策略和客户端，因此当前版本以公式返回的 `asOf` 日期和有效覆盖率检查数据是否新鲜，不在选股命令中隐式刷新行情。

临时需要恢复全部 A 股范围时可以显式运行：

```bash
npm run run:tdx-formulas -- --market 5 --fresh
```

## 页面

打开：

```text
http://localhost:5173/tdx-formulas.html
```

主看板顶部也有“公式选股”入口。页面展示运行状态、搜索范围、K 线口径、每个公式的命中数、有效覆盖和转债清单。页面只读取最近快照，不会在打开页面时触发通达信计算。
