# 可转债量化实验室：日线回测、日内回放与模拟盘

## 真实调用链

```text
quant.html / quant.js
  -> Node /api/cb-quant/backtest
    -> MiniQMT /daily（日K缓存）
    -> MiniQMT /daily?reference=1（本地分钟聚合补缺）
    -> 最近交易日仍缺失时：/intraday-backfill -> 分钟聚合日K
      -> lib/cb-quant-engine.js（六个原有日线策略、回测撮合）

  -> Node /api/cb-quant/replay
    -> MiniQMT /bond（分钟指标）
      -> 分钟不完整时自动请求 /intraday-backfill，完成后重读
    -> MiniQMT /events（主力监控事件）
    -> runtime/auction-series.json（09:15–09:25竞价债股配对）
      -> lib/cb-intraday-engine.js（日内状态机、折扣凯利、撮合）

Node /api/cb-quant/paper/*
  -> 可选原有六个日线策略或日内组合确认
  -> MiniQMT /quotes（有效实时价）
  -> lib/cb-quant-engine.js（纸面现金、持仓、费用）
  -> runtime/cb-paper-account.json
```

量化实验室不会调用 `/api/miniqmt/trading/*`、`scripts/trading_execution.py` 或 QMT 真实委托/撤单接口。

## 原有日线功能

- 完整保留 `MA20`、日线 `MACD`、`EMA 5/20`、日线紫线、布林回归和唐奇安突破六种策略。
- 单策略可查看权益、基准和逐笔成交；“全部策略对比”统一费用、滑点和仓位口径。
- 日线回测和日线模拟盘仍采用收盘信号、下一根日K/下一交易时段有效报价成交，日内模式是并列新增功能。

## 日内状态机

1. `AUCTION`：只采纳 09:25 带成交额确认的转债—正股配对；此前虚拟撮合价只展示，不当作成交或方向事实。
2. `SETUP`：复用 `purple_line_pullback_reclaim` 或 `intraday_average_pullback_reclaim`，只表示进入观察，不能直接买入。
3. `TRIGGERED`：要求已完成分钟同时站上紫线和分时均价、紫线高于 `purple_ma27`、暗盘资金转流入、MACD为正，且 3/5 分钟动量与至少两类事件交叉确认。
4. `POSITION`：触发后按下一分钟开盘价加滑点成交，避免同一分钟高低价的未来数据。
5. `TAKE1 / TAKE2 / STOP_EXIT`：结构止损、1R分步止盈、目标R退出；第一止盈后启用带缓冲的紫线移动保护；同一分钟同时触发时止损优先。
6. `TIME_EXIT`：14:50 前后退出，不隔夜。

## 凯利与止盈止损

- 凯利公式：`f* = p - (1-p)/b`，其中 `p` 是胜率先验，`b` 是目标收益/风险比。
- 默认使用四分之一凯利，再受单笔风险 0.5% 和总仓位 20% 双上限约束。
- 凯利只决定风险预算，不产生方向信号，也不直接产生价格点位。
- 止损来自信号前 5 根已完成分钟的结构低点，加缓冲且最宽不超过 2%。
- 止盈来自止损距离：默认一半在 1R，剩余在 2R。
- 当前默认 52% 胜率属于人工先验，少于 30 个历史样本时标记 `manual_assumption_insufficient_sample`，不得写成已校准胜率。

## 数据与成交边界

- 正常完整交易日应有约 241 根一分钟K；不补造停牌或缺失分钟。
- 回放发现分钟缺口会先自动读取 MiniQMT 缓存；仍不完整则提交串行补数任务，任务完成后重新读取。实时 Monitor 运行时不抢占 Bridge；Monitor 停止后的周末允许人工回放补数。
- 主力监控事件是项目在当时根据行情实时生成的派生事件，若当时 Monitor 未运行，普通历史行情只能补分钟K，不能原样重建事件。
- 09:25 竞价快照必须来自当日已留存竞价采样；一分钟K不能冒充历史竞价原始快照。采样同时写入 `runtime/auction-series-history/YYYYMMDD.json`，避免新交易日覆盖旧日回放数据。
- 主力资金、五档支撑和竞价都是 MiniQMT L1 汇总或公式近似，统一标记为非 Level-2 逐笔事实。
- 回放使用已落库事件和分钟K；事件确认后的下一分钟开盘成交，计入双边佣金与单边滑点。
- 模拟盘只接受连续交易时段、当日且 180 秒内的行情；信号超过 180 秒不追单。
- 模拟盘买入立即可卖，体现可转债 T+0；数量按 10 张整数倍。
- 服务重启后模拟轮询安全停止，需在页面手动恢复。

## 尚未覆盖

- 20–30 个交易日以上的事件胜率/盈亏比校准与 Walk-Forward。
- Level-2 逐笔成交、完整订单簿、排队、部分成交与冲击成本。
- 历史每日债池和转股价、强赎、下修、回售等条款 PIT。
- 临停、异常交易规则和不同券商最小费用的逐笔重建。
- QMT Bridge 的昨日历史成交：当前当日成交接口在次日不能回查，若本地审计也无记录，只能复盘行情，不能声称复盘了用户真实成交。

因此结果是工程验证和统计回放，不是样本外稳定性、真实可成交收益或投资建议。
